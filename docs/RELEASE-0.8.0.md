# Koda 0.8.0 Immersive Listening

基於 Koda 0.7.2 Build 16401。沉浸式畫面與一般播放器共用同一個播放引擎、佇列、音效、歌詞資料與時鐘。

## 使用方式

在正在播放的「⋯」選單中選擇「沉浸式聽歌」。沉浸畫面的「⋯」可切換四種樣式，也能調整歌詞、封面、背景、音譜、控制列及螢幕。iPhone 可開啟「橫向時自動進入」，預設關閉。下次進入會使用上次選定的樣式。

| 樣式 | 主要區域 |
| --- | --- |
| 歌詞劇院 | 大字雙語歌詞與可調整的補充封面區 |
| 專輯展演 | 大幅封面、歌詞，以及方形、黑膠或玻璃封面樣式 |
| 音譜沉浸 | 大幅音訊視覺化及可調位置的歌詞 |
| 極簡歌詞 | 超大型歌詞與可自動隱藏的播放控制 |

個別樣式保存字體、行距、對齊、翻譯、背景、封面、音譜和控制列設定。設定面板變更會反映在播放器上。可重設目前樣式，或確認後重設全部沉浸設定。

## 音訊視覺化

視覺化重用 AVPlayerItem 的 EQ／AutoMix 音訊處理 Tap。音訊回呼只在分析端持有短期讀取需求時，把曲目的第一聲道 PCM 放進預先配置的緩衝。Tap 以非阻塞方式交換資料。分析端對 PCM 加窗後使用 Accelerate FFT，並計算 RMS、峰值及無偽造資料的時域波形。畫面使用 Canvas 繪製。

- 直立條形、上下對稱及環形頻譜使用實際頻段能量。
- PCM 波形使用實際解碼樣本的下採樣結果。
- 交叉淡化期間分析目前曲目的已處理 PCM，輸出裝置的混音與音量在這個取樣點之後。
- 暫停、關閉頁面、背景、緩衝及嚴重過熱會停止分析或清除畫面資料。低耗電和省電模式採用較低更新率及較少頻段。
- 本機下載、YouTube Music 串流、AirPlay 或藍牙能否提供 PCM，取決於 AVPlayerItem 及實際路由。無法取得樣本時顯示「目前無法取得音譜」。MV 使用原有獨立影片介面。

## 歌詞與翻譯

歌詞來源面板可依逐字、逐行或純文字篩選。疑似不同錄音版本預設收合。來源狀態獨立呈現，仍可手動查詢、匯入、校正與編輯。同步預覽跟隨目前播放位置，僅在確認後套用候選。

所有已啟用來源確認無結果時，會暫存結果 24 小時。逾時、限流、取消等暫時失敗仍可再次查詢。HTTP 429 冷卻依來源跨歌曲共用，手動搜尋也會遵守冷卻。使用者可從播放器或歌詞面板標記純音樂；標記保存在目前帳號的資料庫，可搜尋、排序及批次解除。

自動翻譯使用 Apple Translation。歌詞內建、匯入及手動編輯的譯文仍可使用。Apple Intelligence 歌詞工作、比較、設定和診斷已移除。舊的 AI 來源選擇會改用 Apple Translation。翻譯設定可清除已退役的 AI 專用快取與生成譯文。既有手動譯文仍存放在個別歌詞版本；舊生成紀錄若包含手動編輯的副本，先以原始版本識別另存，再移除生成內容。

## AirPlay、螢幕和防誤觸

AirPlay 延遲以 0.1 秒為單位，範圍 –10 至 +10 秒。正值延後顯示。AirPlay 連線時才將共用的接收端校正加到原有歌曲及版本校正，斷線即回到一般校正。舊 CarPlay 延遲不帶入 AirPlay。iOS 的輸出識別資料不足以保證跨次連線的裝置比對，因此共用 AirPlay 設定。

Koda 專用 CarPlay Scene、Widget、Live Activity、Intents 和簽署資源已移除。一般 Widget、系統播放控制、AirPlay 和背景音訊仍由各自的既有管線提供。舊活動的系統清理由 iOS 管理。

沉浸畫面預設在前景維持恆亮，暫停時也適用。退出或背景時釋放恆亮需求。iPhone／iPad 可選用自訂亮度，離開畫面時會在適當情況恢復進入前的值。Catalyst 提供手動進出與畫面設定。

觸控鎖定後只保留鎖頭。五秒後隱藏，點一下畫面只會喚回鎖頭，下一次按可見的鎖頭才解除鎖定。歌詞及音樂仍繼續同步。系統手勢、音量鍵、電源鍵和耳機控制照常交由系統處理。

## 驗證

以 GitHub Actions 的 Xcode 27 工作流程驗證 Core、iOS Release、Mac Catalyst、大小尺寸 UI、橫向鎖定回歸、版本及打包。發行結果以最終 GitHub Actions 與推薦 IPA 的 SHA-256 為準。

實機驗收重點包括 YouTube Music PCM、下載、AirPlay 與藍牙、AutoMix／交叉淡化、播放中旋轉、觸控鎖定及 VoiceOver、控制中心手動亮度、Apple 語言包與長時間耗電。
